# لوحة تحكم إدارية عامة — admin13

لوحة تحكم إدارية **عامة وقابلة لإعادة الاستخدام**، مبنية بـ Laravel 12 + Inertia 2 + Vue 3 (تطبيق واحد).
الفكرة: قاعدة جاهزة تُبنى عليها أي لوحة تحكم لأي نشاط — بدل إعادة بناء المصادقة والصلاحيات
والعملاء والإعدادات في كل مشروع من الصفر.

---

## نظرة سريعة

| البند | القيمة |
|---|---|
| الإطار | Laravel 12 + Inertia 2 (بدون API منفصل) |
| الواجهة | Vue 3.5 (SFC) + Vite 6 + Tailwind 3.4 |
| قاعدة البيانات | MySQL |
| الاتجاه | RTL كامل، كل النصوص عربية |
| الثيم | AdminLTE (خلفية فاتحة، بطاقات بيضاء، قائمة جانبية داكنة) |
| التراسل | واتساب عبر بوابة [c-wts.com](https://c-wts.com/docs) |


## التشغيل

```bash
# 1) الاعتماديات
composer install
npm install

# 2) البيئة
cp .env.example .env
php artisan key:generate

# 3) قاعدة البيانات (MySQL — أنشئ قاعدة باسم admin13)
php artisan migrate --seed

# 4) التشغيل (نافذتان)
php artisan serve      # http://localhost:8000
npm run dev            # Vite + HMR
```

للإنتاج: `npm run build`

## نظام الجداول

كل جدول في المشروع يستخدم نفس المكوّنات — استوردها من ملف واحد:

```ts
import { DataTable, StatPill, StatusBadge, TableActionButton, type Column } from '@/components/data-table';
```

| المكوّن | الاستخدام |
|---|---|
| `DataTable` | الجدول الكامل (أعمدة + slots للخلايا + ترقيم صفحات) |
| `StatusBadge` | شارة حالة صلبة اللون (`success` / `danger` / `warning` / `info` / `primary` / `neutral`) |
| `TableActionButton` | زر إجراء مربّع ملوّن (`danger` / `edit` / `view` / `success` / `warning`) |
| `StatPill` | حبّة إحصائية صغيرة |
| `SmallBox` | مربّع إحصائي ملوّن أعلى الصفحة (نمط AdminLTE) |

**بنية صفحة الجدول الموحّدة** (كما في العملاء والموظفين والتذاكر):

```
مربّعات إحصائية (SmallBox)
└── بطاقة .lte-card
    ├── .lte-card-header   → العنوان + بحث + فلاتر + أزرار
    ├── الجدول             → رأس فاتح، نص أسود، تظليل عند المرور، شارات، أزرار outline
    └── .lte-card-footer   → «عرض X إلى Y من Z» + ترقيم الصفحات
```

**قواعد:** أنماط الحقول وألوان نصوص الجداول مضبوطة **مركزياً** في `resources/css/app.css`
— لا تكرّرها في الصفحات.

## تكامل الواتساب

كل الاتصال بالبوابة يمرّ عبر `app/Services/WaGateway.php` — نقطة التغيير الوحيدة عند تبديل المزوّد.

- **الإعداد:** `/admin/settings/whatsapp` → التفعيل + `Instance ID` + `Access Token` (يُخزَّن مشفّراً).
- **التحقق:** زر «التحقق من الاتصال» + إرسال تجريبي لأي رقم.
- **الترحيب الآلي:** عند إضافة عميل جديد يُرسل قالب الترحيب تلقائياً (عبر Observer)،
  ويدعم المتغيّرات `{name}` و`{business}`.

---

## عند البناء على هذه القاعدة

1. أضف الـ migration والـ Model والـ Controller للوحدة الجديدة.
2. سجّل مفاتيح صلاحياتها في `RolesController::permissionKeys()` لتظهر في مصفوفة الأدوار.
3. أنشئ الصفحة في `resources/js/pages/admin/` باتباع **بنية صفحة الجدول الموحّدة** أعلاه.
4. أضف الرابط في `routes/web.php` وعنصر القائمة في `AppSidebar.vue`.

## ملاحظات

- الأدوار الافتراضية: **مدير عام** (كل الصلاحيات، غير قابل للحذف) · **محرر** · **مشاهد**.
- `ClientsSeeder` يضيف 10 عملاء تجريبيين ويستخدم `updateOrCreate` على الجوال — تشغيله مجدداً لا يكرّر البيانات.
- صفحتا **الأدوار** و**الإشعارات** لا تتبعان نمط الجدول عمداً: الأولى شبكة بطاقات بمصفوفة صلاحيات،
  والثانية قائمة تغذية (feed).
